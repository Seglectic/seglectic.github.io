- Been working on some software that automatically slices a hollowed out model up for preparing on my CNC laser cutter, while doing so I realized I have a need for print-in-place hinges.
- There are a few out there but the ones I've found either had way too many options or weren't very performant. and the rest were stuff you had to have other CAD software for.
- I figure I would add to the pile much like the many gridfinity generators of yore (they're almost certainly still spawning) and make my own.
- V1's already done and looks pretty good, I'll make a Printables profile for it cause people might find it genuinely useful and the main one I found there was the one that required OpenSCAD by Rohin Gosling (great name).
- Anyhow we have some pretty simple butt hinges and they do the thing but there's room for more types.
	- I'll probably leave living hinges out of the equation but tapered strap, surface and snap-on hinges could definitely be worthwhile endeavors.
	- https://3dprintcad.com/app/?project=mw74aw0tla4oc This project on 3DPrintCAD has a good generator as well and it's pretty performant.
		- Just not a huge fan of the UI or that it's attached as part of a much bigger project, I'm sure that OnShape has a ton of em too but bleh.
- Anyway that's that, first released blog in a while, neat. I guess this thing still works.
